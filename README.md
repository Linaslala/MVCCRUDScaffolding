# MVCCRUDScaffolding

An ASP.NET Core MVC CRUD application for bank transactions, built with the built-in **scaffolding** and **Entity Framework Core**. It shows the standard CRUD workflow: List, Create, Details, Edit and Delete.

## Tech stack

- **ASP.NET Core MVC** (.NET 10)
- **Entity Framework Core** (Code First with migrations)
- **Microsoft.VisualStudio.Web.CodeGeneration.Design** for scaffolding
- Bootstrap views generated by the scaffolder

## Features

- List transactions
- Create, edit, delete and view details of transactions
- EF Core migrations generated from the `Transaction` model

## Getting started

```bash
git clone https://github.com/Linaslala/MVCCRUDScaffolding.git
cd MVCCRUDScaffolding
dotnet restore
dotnet ef database update
dotnet run --project MVCCRUDScaffolding
```

Update the connection string in `appsettings.json` to match your SQL Server instance before applying the migration.
